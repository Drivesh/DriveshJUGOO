Connect to your website

Your changes are saved straight to your GitHub repository. You connect once per device with a GitHub access token — it stays in this browser only and is never put on the website.

First time? Create your token (2 minutes)
  1. Open GitHub → New fine-grained token (sign in if asked).
  2. Token name: Website editor · Expiration: 1 year (or your choice).
  3. Repository access: Only select repositories → choose your website repository.
  4. Permissions → Repository permissions → Contents: Read and write. Leave everything else.
  5. Click Generate token, copy it (starts with github_pat_) and paste it below.

Edit your website

Open a section, make changes, then press Publish. Use Preview to check first. The live site updates about 1–2 minutes after publishing.
